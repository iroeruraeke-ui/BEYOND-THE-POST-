# Beyond the Post — Complete Front-End Publication

This package is a professional, responsive publication website prototype.

## Included
- Professional homepage
- Latest stories
- Article detail pages
- Search
- Categories and category pages
- About page
- Contact page
- Newsletter subscription demo
- Admin dashboard prototype
- Responsive mobile/desktop styling
- SEO title/description on core pages
- Editorial structure and 12-category publication architecture

## Important
The included admin dashboard is a front-end prototype. A genuinely complete publishing system with secure login, database storage, image uploads, authors, comments, scheduled publishing and real newsletter delivery requires a backend/CMS such as Supabase, WordPress, or another database/auth service.

## Deployment
This package can be deployed as a static site to GitHub Pages, Vercel, Netlify, or similar hosting.
